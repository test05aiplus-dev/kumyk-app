# Къумукъ тил — Android-приложение для изучения кумыкского языка

Приложение работает полностью офлайн. Интерфейс — HTML/JS в `app/src/main/assets/www`,
оболочка — нативная Activity с WebView (Java, minSdk 26 / Android 8+, targetSdk 35).

## Что внутри

- **Главная** — слово дня, кнопка «Продолжить урок», общий прогресс, быстрые ссылки.
- **Уроки** — разбиты на 4 этапа (как программа на сайте). В каждом уроке 7 форматов по порядку:
  теория → экспресс-словарь → 3D-флешкарточки с интервальным повторением → спринт →
  упражнения с разбором ошибок → «Найди пару» → итоговый тест (80% — урок пройден).
- **Словарь** — Къумукъ → Русский и Русский → Къумукъ, поиск с подсветкой, фильтр «Слова курса», счётчик.
- **Спринт** — 60 секунд, слова из всех уроков, множитель за серию, рекорд.
- **Диалоги и пословицы** — реплики-пузыри, переключатель «Без перевода».
- **Профиль** — имя, пройденные уроки, слова в долгой памяти, очки, дни подряд, сброс прогресса.

Прогресс хранится на телефоне (localStorage). Системная кнопка «Назад» работает по истории экранов.

## Как получить APK

### Вариант 1: GitHub (без установки чего-либо)
1. Создайте репозиторий на GitHub и загрузите туда содержимое этой папки.
2. Откройте вкладку **Actions** → «Сборка APK» запустится сама (или нажмите **Run workflow**).
3. Через 3–5 минут скачайте артефакт `kumyk-app-apk` → внутри `app-debug.apk`.
4. Перекиньте APK на телефон и установите (разрешите установку из неизвестных источников).

### Вариант 2: Android Studio
1. File → Open → выберите папку `KumykApp`.
2. Дождитесь синхронизации Gradle.
3. Build → Build APK(s), либо подключите телефон и нажмите Run.

Для Google Play: Build → Generate Signed App Bundle, создайте ключ и храните его отдельно от проекта.

## Как менять контент

Все уроки, слова, диалоги и пословицы лежат в одном файле:
`app/src/main/assets/www/data.js`

- Новый урок — добавьте объект в `LESSONS` (поля `id`, `stage`, `title`, `goal`, `theory`, `words`, `exercises`).
- Новые слова словаря — добавьте пары `["кумыкское", "русское"]` в `EXTRA_DICT`.
- Большой словарь (десятки тысяч статей) можно загрузить тем же форматом — поиск показывает первые 300 совпадений.

**Важно:** сейчас в приложении демонстрационный набор (8 уроков, около 140 слов).
Перед публикацией тексты, примеры и особенно пословицы должен проверить носитель языка.

Быстро посмотреть интерфейс без сборки: откройте `app/src/main/assets/www/index.html` в браузере Chrome.
