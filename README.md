# Къумукъ тил — Android-приложение для изучения кумыкского языка

Приложение работает полностью офлайн. Интерфейс — HTML/JS в `app/src/main/assets/www`,
оболочка — нативная Activity с WebView (Java, minSdk 26 / Android 8+, targetSdk 35).

## Что внутри

- **Главная** — слово дня, кнопка «Продолжить урок», общий прогресс, быстрые ссылки.
- **Уроки** — разбиты на 4 этапа (как программа на сайте). В каждом уроке 7 форматов по порядку:
  теория → экспресс-словарь → 3D-флешкарточки с интервальным повторением → спринт →
  упражнения с разбором ошибок → «Найди пару» → итоговый тест (80% — урок пройден).
- **Словарь** — Къумукъ → Русский и Русский → Къумукъ, поиск с подсветкой, фильтр «Слова курса», счётчик.
- **Спринт** — 60 секунд, слова из всех уроков, множитель за серию, рекорд.
- **Диалоги и пословицы** — реплики-пузыри, переключатель «Без перевода».
- **Профиль** — имя, пройденные уроки, слова в долгой памяти, очки, дни подряд, сброс прогресса.

Прогресс хранится на телефоне (localStorage). Системная кнопка «Назад» работает по истории экранов.

## Как получить APK

### Вариант 1: GitHub (без установки чего-либо)
1. Создайте репозиторий на GitHub и загрузите туда содержимое этой папки.
2. Откройте вкладку **Actions** → «Сборка APK» запустится сама (или нажмите **Run workflow**).
3. Через 3–5 минут скачайте артефакт `kumyk-app-apk` → внутри `app-debug.apk`.
4. Перекиньте APK на телефон и установите (разрешите установку из неизвестных источников).

### Вариант 2: Android Studio
1. File → Open → выберите папку `KumykApp`.
2. Дождитесь синхронизации Gradle.
3. Build → Build APK(s), либо подключите телефон и нажмите Run.

Для Google Play: Build → Generate Signed App Bundle, создайте ключ и храните его отдельно от проекта.

## iPhone

Есть два способа, оба используют тот же интерфейс и уроки из `app/src/main/assets/www`.

### Сайт на экран «Домой» (без аккаунта Apple)
1. Репозиторий → Settings → General → внизу «Change visibility» → Public
   (на бесплатном аккаунте GitHub Pages работает только с публичными репозиториями).
2. Settings → Pages → Source: **GitHub Actions**.
3. Actions → «Сайт для iPhone (экран «Домой»)» → Run workflow. Адрес сайта появится
   в Settings → Pages (вида `https://<аккаунт>.github.io/kumyk-app/`).
4. На iPhone откройте адрес в Safari → «Поделиться» → «На экран Домой».
   Приложение работает без интернета; озвучка — встроенным турецким голосом iOS.

### Нативное приложение (App Store / TestFlight)
Папка `ios/`: Swift-оболочка с WKWebView и озвучкой через AVSpeechSynthesizer.
GitHub собирает её на Mac (workflow «Сборка iOS»): в артефакте `KumykTil-ios` лежат
неподписанный `KumykTil-unsigned.ipa` и проект Xcode.
- **App Store / TestFlight:** нужен аккаунт Apple Developer ($99/год). На Mac:
  `brew install xcodegen && cd ios && xcodegen generate && open KumykTil.xcodeproj`,
  выбрать свою команду в Signing & Capabilities, Product → Archive → Distribute.
- **Без аккаунта, для себя:** установить `KumykTil-unsigned.ipa` через Sideloadly
  или AltStore со своим Apple ID (нужен компьютер; подпись действует 7 дней).

## Как менять контент

Все уроки, слова, диалоги и пословицы лежат в одном файле:
`app/src/main/assets/www/data.js`

- Новый урок — добавьте объект в `LESSONS` (поля `id`, `stage`, `title`, `goal`, `theory`, `words`, `exercises`).
- Новые слова словаря — добавьте пары `["кумыкское", "русское"]` в `EXTRA_DICT`.
- Большой словарь (десятки тысяч статей) можно загрузить тем же форматом — поиск показывает первые 300 совпадений.

**Важно:** сейчас в приложении демонстрационный набор (8 уроков, около 140 слов).
Перед публикацией тексты, примеры и особенно пословицы должен проверить носитель языка.

Быстро посмотреть интерфейс без сборки: откройте `app/src/main/assets/www/index.html` в браузере Chrome.

## Премиум-разделы (условно платные, тестовый режим)

На главной — группа «Премиум»: фразеологический словарь, словари синонимов и антонимов,
пословицы и поговорки, этимология, стихи кумыкских классиков, из кумыкской истории.
Содержимое — в `data.js` (`PHRASES` и `PREMIUM_SECTIONS`); в каждом разделе первые
записи открыты бесплатно. Наполнение демонстрационное и требует проверки специалистом;
тексты стихов не включены — добавьте их в `poems` у нужного поэта:
`{ title: "Название", text: "строки на кумыкском", ru: "перевод (необязательно)" }`.

## Фразеологический словарь (условно платный, тестовый режим)

Раздел на главной: первые `FREE_PHRASES` выражений из `PHRASES` (в `data.js`) открыты всем,
остальные — после «покупки». Оплата только **имитируется**: деньги не списываются.
Для проверки: тариф «Месяц 199 ₽» / «Навсегда 990 ₽» → «Оплатить (тест)», или промокод
`KUMYK` / `TEST`. В профиле — статус и кнопка «Отключить премиум (для теста)».

Для настоящих продаж цифрового контента магазины требуют свои системы оплаты:
Google Play Billing на Android и In-App Purchase в App Store. Их подключают вместо
функции `grantPremium` в `app.js` перед публикацией.

## Озвучка

Кнопка с динамиком есть у слова дня, в экспресс-словаре, на флешкарточках, в словаре,
в примерах теории. Диалоги и пословицы можно прослушать целиком кнопкой «Слушать»
(у собеседников разная высота голоса) или по одной реплике нажатием.

1. **Записи носителя языка** (приоритет). Положите файлы в `app/src/main/assets/www/audio/`,
   имя файла — само слово: `алма.mp3`, `сав бол.mp3`. Подходят mp3, m4a, ogg, wav.
   Полный список того, что записать, — `audio/ЧТО_ЗАПИСАТЬ.txt`. Список файлов
   приложение собирает само при сборке, ничего прописывать не нужно.
2. **Синтез речи телефона** — для слов без записи. Кумыкского голоса не существует,
   поэтому используется турецкий голос по латинской транскрипции (близкая фонетика),
   а если его нет — русский. Это приблизительное произношение; отключается в профиле.
